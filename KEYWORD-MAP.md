# Keyword map: izzylabs.ca

Each search phrase has **one** page that owns it. If you add a page, add its
row here first.

The brand search isn't winnable soon. "izzylabs" brings up a Telegram channel,
an EVE Online tool, an NFT project and a computer repair shop in California.
So the map targets **capability + place**, and lets the case studies rank for
the products' own names.

Rank data comes from Search Console, 11 Jul to 10 Oct 2026. "—" means no
impressions yet.
